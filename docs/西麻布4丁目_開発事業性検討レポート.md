# 西麻布4丁目 土地（FACE西麻布）開発事業性検討レポート

作成日: 2026-09-08　　対象: 東京都港区西麻布4-3-7（地番 4-11-17, 11-18, 48-5）　　募集価格: 25億円（税込）

---

## 1. 結論（先に要点）

| 項目 | 結論 |
|---|---|
| **募集価格25億円（2,497万円/坪）の評価** | 開発用地としては **高い**。どの用途でも基準ケースで事業採算が成立しない。 |
| **ホテル** | **不成立**。アップスケール（29室・ADR 4.5万円）で NOI利回り 2.3%、収益価格 19億円 ≒ 総事業費の半分。土地に払える上限は約 **8〜14億円**。 |
| **分譲マンション** | **唯一成立し得る用途**。ただし専有257坪・9戸程度の小規模高級物件で **販売坪単価1,800万円以上** が必要（25億で利益率15%）。坪1,500万なら土地 **19億円台** が上限。 |
| **賃貸レジデンス / 店舗ビル建替** | 不成立（NOI利回り 0.8% / 1.9%）。 |
| **現況保有（建替えず再テナント付け）** | 表面3.8%・NOI 2.7%。港区店舗ビルの取引利回り（NOI 3.5%想定）で **収益価格 約18億円**。 |
| **推奨** | 分譲マンション用地として、**指値 19〜20億円（坪1,900〜2,000万円）** を起点に交渉。 <br>売主が25億に固執するなら見送り。ホテル前提での購入は推奨しない。 |

補足: 売主側の「価格交渉可」「売主直」という条件は、この価格が現況賃料（年9,570万円）からの逆算で置かれているだけで、開発用地としての裏付けが弱いことを示唆する。

## 3. 法規制と建築可能ボリューム

### 3.1 容積率
- 第一種住居地域（指定300%）: 前面道路幅員 7.1m × 0.4 = **284%** が上限（指定容積を下回る）。
- 近隣商業地域（指定400%）: 7.1m × 0.6 = 426% → **400%**。
- 敷地が両地域に跨るため面積按分。近商部分の割合は用途地域図で要確認。

| ケース | 近商割合 | 許容容積率 | 容積対象床面積 |
|---|---|---|---|
| 保守 | 0% | 284% | 940㎡ |
| **基準** | **15%** | **301%** | **998㎡** |
| 上振れ | 40% | 330% | 1,092㎡ |

### 3.2 高さ・日影
- 港区は高度地区に絶対高さ制限を導入済み。第一種住居地域には日影規制（測定面4m）が掛かる。
- 周辺は5〜8階建（ブルーミング西麻布8F、泉西麻布ビル8F、麻布エミネンス5F等）。**地上6〜7階＋地下1階**が現実的な想定。
- 建ぺい率は加重で約63%。1フロア約150〜200㎡。

### 3.3 用途別の可否
- **ホテル**: 第一種住居地域内でもホテル・旅館は床面積3,000㎡以下なら可。本件は約1,050㎡で可。
- **共同住宅**: 可。港区のワンルーム規制（住戸25㎡以上等）は高級ファミリー型なら影響なし。
- **駐車場附置**: 延床約1,050〜1,250㎡は東京都駐車場条例の附置義務対象（特定用途2,000㎡超等）を下回る見込み。自転車駐車場は港区条例の確認要。
- **中高層紛争予防条例**: 港区条例に基づく近隣説明が必要。

### 3.4 想定ボリューム（基準ケース）

| 用途 | 延床（容積不算入含む） | 有効面積 |
|---|---|---|
| 分譲・賃貸マンション | 約1,247㎡（377坪）※共用廊下・階段・EV不算入で1.25倍 | 専有 848㎡（**257坪**）・約9戸（1戸約95㎡） |
| ホテル | 約1,057㎡（320坪）※廊下は容積算入 | 宿泊特化 37室 / アップスケール 29室 / ラグジュアリー 21室 |
| 店舗ビル | 約1,047㎡（317坪） | 貸室 257坪 |

## 4. 用途別収支（土地25億円・基準ケース）

共通前提: 仲介3%＋税、登録免許税・不動産取得税（固定資産税評価 約6.9億円想定）、固都税年1,300万円、解体（RC・地下あり 15万円/坪＋アスベスト等2,000万円）約6,000万円、設計監理5%、予備費3%、金利2.0%＋融資手数料0.5%、事業期間27か月（退去3＋解体3＋工事18＋引渡3）。

### 4.1 分譲マンション（本体工事 200万円/坪、販売坪単価 1,500万円）

| 項目 | 金額 |
|---|---|
| 土地代 | 25.00億円 |
| 取得諸経費（仲介・税・その他） | 1.18億円 |
| 固都税（事業期間）・解体・退去前賃料収入 | 0.65億円（0.29＋0.60−0.24） |
| 本体工事費（377坪 × 200万円） | 7.54億円 |
| 設計監理・外構等・予備費 | 0.91億円 |
| 販売経費（売上5%） | 1.92億円 |
| 金利・融資手数料 | 1.70億円 |
| **総事業費** | **38.90億円** |
| 売上高（257坪 × 1,500万円） | 38.48億円 |
| **事業利益** | **▲0.42億円（▲1.1%）** |
| 損益分岐 販売坪単価 | **1,516万円/坪** |

→ 25億円で利益率15%を確保するには **販売坪単価1,800万円**（1戸約95㎡で約5.2億円）が必要。港区の新築平均坪単価は2025年 696万円、2026年1〜4月 758万円。西麻布の小規模高級物件で1,500万円は狙える水準だが、1,800万円は最上位ブランドの領域。

### 4.2 ホテル（3グレード）

| 項目 | 宿泊特化 | アップスケール | ラグジュアリー |
|---|---|---|---|
| 客室数（延床/室） | 37室（28㎡） | 29室（36㎡） | 21室（50㎡） |
| ADR / 稼働率 | 28,000円 / 85% | 45,000円 / 80% | 90,000円 / 72% |
| 年間総売上 | 3.31億円 | 4.12億円 | 5.71億円 |
| 所有者NOI（総売上の26%−固都税） | 0.65億円 | 0.86億円 | 1.28億円 |
| 総事業費（FF&E・開業費込） | 36.90億円 | 37.86億円 | 39.83億円 |
| **NOI利回り（総事業費比）** | **1.8%** | **2.3%** | **3.2%** |
| 収益価格（Cap 4.5%） | 14.5億円 | 19.2億円 | 28.4億円 |

→ ラグジュアリーでも ADR 12万円超（稼働72%）が必要。100坪・私道接道・広尾徒歩7分の立地でこの単価を取れる運営者は限られ、運営者リスクを所有者が負う。**ホテル用地として25億円は成立しない**。CBREの2026年3月調査で東京ホテルの期待利回りは4.2%と過去最低であり、キャップレートの低下余地も乏しい。

| 年間総収入 | 0.64億円 | 1.02億円 | 0.89億円 |
| NOI | 0.31億円 | 0.66億円 | 0.63億円（現行 0.70億円） |
| 総事業費／取得費 | 36.89億円 | 35.55億円 | 26.18億円 |

## 7. 推奨戦略と交渉方針

1. **用途は分譲マンション一択**。ホテルは検討から外す（運営者付きでも土地に払える額は最大14億円台）。
2. **指値は19〜20億円**（坪1,900〜2,000万円）。根拠として残余法（坪1,500万円販売・利益率15%）を提示。売主は「価格交渉可」と明言しており、現況賃料ベースの3.8%も市場並みで強気材料は少ない。
3. **保証金2,070万円の承継分**と、退去時期が契約終了（2027/7）まで延びた場合の賃料継続を条件面で整理。合意解約書がなければ「1月末退去」を売主の表明保証にする。
4. **22億円超は見送り**。坪1,600万円以上の販売を前提にしないと15%を確保できず、2028〜29年の販売時点の市況リスクを負う。
5. 代替案として、既存建物を保有し続ける前提なら **17〜18億円**が上限。開発しないならこの水準以外に買う理由はない。

## 8. 購入検討時のデューデリジェンス項目

- [ ] 用途地域境界の位置（港区都市計画情報サービス）→ 近商割合と容積率の確定
- [ ] 高度地区・日影規制・絶対高さ制限（港区）→ 階数の確定、ボリュームチェック（設計事務所）
- [ ] 西側公道の認定幅員（7.1mの根拠）、南側私道の所有関係・通行掘削承諾・位置指定の有無
- [ ] 確定測量・越境・境界確認（実測なし）
- [ ] 賃借人の退去合意書（2027年1月末）と保証金返還債務の承継条件
- [ ] 既存建物のアスベスト調査、地下躯体・杭の撤去範囲と埋設物、土壌汚染（店舗用途歴）
- [ ] 港区 中高層建築物紛争予防条例、自転車駐車場条例、ワンルーム条例の該当確認
- [ ] 販売坪単価の裏付け：近隣新築（西麻布・広尾・南麻布）の成約事例、ブランド販売力
- [ ] 建築費見積（2社以上）。2026年は資材・労務費の上昇が続き、坪200万円は下限に近い
- [ ] 融資条件（金利2%想定の妥当性、LTV、工事期間中の資金繰り）
