## Q1. 会社情報・開示範囲・実績

市側の要望: 「クライアントの詳細情報開示（担当: 商工課 鈴木係長へ）」「現場のデータセンター実績の有無確認」「会社情報・会社概要」

1. 市に提出してよい会社概要（日本法人 BE Enertrans G.K. と Enertrans Global の関係、所在地、設立、資本金、株主構成、事業内容、従業員数）。公開可の資料（会社案内PDF等）があれば添付ください。
2. **開示範囲の指定**: ①社名を含め全面開示可／②NDA締結後に開示／③当面は「DC事業者（守秘）」として弊社名義で進める、のいずれか。
3. 本件における貴社の役割: ①用地・電力・許認可をパッケージ化して**DC事業者（ハイパースケーラー等）に提供する開発者**か、②自社でDCを建設・運営するか。①の場合、**エンドユーザー（テナント・買主）は既に決まっているか**、決まっていれば市に説明できる範囲（業種・規模）。
4. データセンターの開発・運営実績（所在地、規模〔MW・延床〕、稼働年、自社運営か委託か）。日本でFS中とされる北海道・茨城の案件の概要（面積・MW・進捗）は市への説明材料になるため、開示できる範囲で。実績がない場合は、運営パートナー（委託先・JV相手）の名称と実績。
5. 資金調達の形（自己資金・借入・ファンド・エンドユーザーの前払い）の概要と、用地取得の主体（貴社／SPC／エンドユーザー）。
6. 市との面談・協議に出席する担当者（役職）と、技術的な質問に答えられる窓口。

## Q2. 電力（市側の「特別電力など電力の必要」「電気が何がいるか」）

1. 希望する**IT負荷（MW）**と**受電容量（MW）**。段階開発なら第1期／最終の2段階で。
2. 希望する受電電圧（66kV／154kV）と回線数（本線・予備線、2ルートの要否）。
3. 供給開始希望時期（例: 第1期 2029年度、最終 2033年度）。
4. 非常用発電機の有無・容量・燃料（軽油／LNG）と燃料貯蔵量（消防協議の前提）。
5. 再エネ・脱炭素電源の要件（RE100対応、PPA、GX戦略地域の補助要件〔脱炭素電源〕を使う意向の有無）。
6. 東京電力PGへの事前相談を弊社が貴社名で行ってよいか、貴社名を伏せて行うか。

## Q3. 必要面積・敷地条件（市側の「近隣の2か所でトータルha揃える可能」）

1. 希望する**合計面積（ha）**と、**1区画の最小面積（ha）**。2か所に分かれても成立するか（分かれる場合の両区画の距離の上限）。
2. 想定する延床面積（㎡）、階数、建ぺい率の目安。
3. 平場の要否（造成済みが条件か、丘陵地の造成を貴社で行えるか）、地耐力の要件。
4. 進入路の条件（大型トレーラー、幅員、高速ICからの距離の上限）。
5. 通信: 必要なダークファイバーのルート数（2ルート冗長の要否）と、東京（大手町等）からの許容距離・遅延。
6. 用地の取得形態（購入／事業用定期借地／自治体分譲地の購入）と、希望する引渡し時期。

## Q4. 水（市側の「水の使用量、処理方法」「水の量」）

1. 冷却方式（空冷／水冷／ハイブリッド／液冷）と、**上水の使用量（㎥/日、年間）**。
2. 排水の量と性状（冷却塔ブロー水の有無、処理方法、公共下水への放流か浄化槽か）。
3. 井水・工業用水の利用可能性、雨水利用の有無。
4. 災害時の給水要件（受水槽の容量、断水時の運転継続日数）。

## Q5. 雇用（市側の「職員の人数」）

1. 稼働時の常駐人数（運用・保守・警備・清掃の内訳）と、うち地元採用の見込み。
2. 建設期間中の作業員数（ピーク）。
3. 本社機能・研究開発機能の併設予定の有無（市の企業立地促進制度は本社機能や一定規模の雇用で加算がある）。

## Q6. 立地条件・気候・災害（市側の「立地条件 気候など」）

1. 気候の要件（外気冷房を前提とする場合の年平均気温・湿度の上限）。日光市・矢板市は冷涼で標高100〜350m程度。
2. 災害の許容条件（活断層からの距離、浸水想定、土砂災害警戒区域、標高、地盤）。
3. 周辺環境の条件（住宅地からの離隔、騒音基準、景観・航空制限）。
4. 既存の候補条件との比較で、貴社が**候補地を落とす条件**（NG条件）を列挙ください。

## Q7. スケジュールと取引条件（市側の「条件」）

1. 用地確定の希望時期、設計着手、着工、稼働の目標年月。
2. 市・県に期待する支援（GX戦略地域の投資補助、系統整備、固定資産税の奨励金、許認可の伴走）。
3. 自治体の新産業団地（分譲）を待てるか、民有地の先行取得を望むか。
4. 契約上の前提（停止条件: 受電容量の確保、開発許可、環境アセス等）。

## Q8. 既存施設・民有地の転用（矢板市のゴルフ場等）

1. 矢板市のゴルフ場（約120ha、丘陵、2027年12月閉鎖予定、太陽光事業者と協議中）を候補として検討する意向があるか。
2. 既存建物（クラブハウス等）の活用は不要か、更地渡しが条件か。
3. 地権者が複数の土地（借地を含む）でも進められるか、一筆・一所有者が条件か。

## Q9. 再エネ・蓄電池の併設（貴社の事業領域に関わる）

1. DC用地に太陽光・蓄電池（BESS）を併設する構想があるか。ある場合の規模（MW／MWh）と必要面積。ゴルフ場120haのうちDCに使わない丘陵部を太陽光・BESSに充てる案は検討対象か。
2. 脱炭素電源の調達方針（オンサイト再エネ、オフサイトPPA、非化石証書）。GX戦略地域の投資補助（脱炭素電源100%で最大50%）の活用を前提にするか。
3. 系統用蓄電池として先行して系統接続を押さえ、DCの受電に転用する考え方（接続枠の確保）を取るか。

## 日光市・矢板市の現状（貴社の判断材料として）

- 日光市: 日光産業団地は完売。新産業団地は日光産業団地（森友・土沢）南側を候補地に可能性調査中で、**来年度（2027年度）までに候補地を決定**。市は「近隣2か所でトータルhaを揃えることは可能」との認識。今後の窓口は商工課 鈴木係長。
- 矢板市: 2026年9月11日に国のGX戦略地域（データセンター集積型）に認定。10年で1GW級・市内2か所約60haを計画し、東京電力HDと連携協定。市内で154kV南北2系統・500kV東西2系統が交差。
- 弊社の進め方: 貴社の回答（特にQ1〜Q3）を受けて市へ条件書を提出し、並行して東京電力PGへ受電の事前相談を行います。候補地は11月中の確定を目指しています。
