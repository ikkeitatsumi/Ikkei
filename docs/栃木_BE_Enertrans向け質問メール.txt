（1）会社概要・開示範囲・実績
 1. 市に提出可能な会社概要（BE Enertrans G.K. と Enertrans Global の関係、所在地、設立、資本金、株主構成、事業内容、従業員数）。会社案内等の資料があれば添付をお願いします。
 2. 開示範囲：A. 社名を含め全面開示可 ／ B. NDA締結後に開示 ／ C. 当面は「DC事業者（守秘）」として弊社名義で進める
 3. 本件における貴社の役割：A. 用地・電力・許認可をパッケージ化してDC事業者（ハイパースケーラー等）に提供 ／ B. 自社でDCを建設・運営
   → Aの場合、エンドユーザー（テナント・買主）は決まっていますか。決まっていれば市に説明できる範囲（業種・規模）をお知らせください。
 4. データセンターの開発・運営実績（所在地、規模〔MW・延床〕、稼働年、自社運営か委託か）。北海道・茨城でご検討中の案件の概要（面積・MW・進捗）も、開示可能な範囲でお願いします。実績がない場合は運営パートナーの名称と実績。
 5. 資金調達の形（自己資金・借入・ファンド・エンドユーザーの前払い等）と、用地取得の主体（貴社／SPC／エンドユーザー）。
 6. 市との協議に出席される担当者（役職）と、技術的な質問にお答えいただける窓口。

（2）電力
 1. 希望するIT負荷（MW）と受電容量（MW）。段階開発の場合は第1期／最終の2段階で。
 2. 希望する受電電圧（66kV／154kV）と回線数（本線・予備線、2ルートの要否）。
 3. 供給開始の希望時期（例：第1期 2029年度、最終 2033年度）。
 4. 非常用発電機の有無・容量・燃料（軽油／LNG）と燃料貯蔵量。
 5. 再エネ・脱炭素電源の要件（RE100対応、PPA、GX戦略地域の補助活用の意向）。
 6. 東京電力パワーグリッドへの事前相談を、貴社名で行ってよいか、貴社名を伏せて行うか。

（3）必要面積・敷地条件
 1. 希望する合計面積（ha）と、1区画の最小面積（ha）。2か所に分かれても成立するか（分かれる場合の両区画の距離の上限）。
 2. 想定する延床面積（㎡）、階数、建ぺい率の目安。
 3. 平場の要否（造成済みが条件か、丘陵地の造成を貴社で行えるか）、地耐力の要件。
 4. 進入路の条件（大型トレーラー、幅員、高速ICからの距離の上限）。
 5. 通信：必要なダークファイバーのルート数（2ルート冗長の要否）と、東京からの許容距離・遅延。
 6. 用地の取得形態（購入／事業用定期借地／自治体分譲地の購入）と、希望する引渡し時期。

（4）水
 1. 冷却方式（空冷／水冷／ハイブリッド／液冷）と、上水の使用量（㎥/日、年間）。
 2. 排水の量と性状（冷却塔ブロー水の有無、処理方法、公共下水への放流か浄化槽か）。
 3. 井水・工業用水の利用可能性、雨水利用の有無。
 4. 災害時の給水要件（受水槽の容量、断水時の運転継続日数）。

（5）雇用
 1. 稼働時の常駐人数（運用・保守・警備・清掃の内訳）と、うち地元採用の見込み。
 2. 建設期間中の作業員数（ピーク）。
 3. 本社機能・研究開発機能の併設予定の有無。

（6）立地条件・気候・災害
 1. 気候の要件（外気冷房を前提とする場合の年平均気温・湿度の上限）。日光市・矢板市は冷涼で、標高はおおむね100〜350mです。
 2. 災害の許容条件（活断層からの距離、浸水想定、土砂災害警戒区域、標高、地盤）。
 3. 周辺環境の条件（住宅地からの離隔、騒音基準、景観・航空制限）。
 4. 候補地を落とす条件（NG条件）があれば列挙をお願いします。

（7）スケジュールと取引条件
 1. 用地確定の希望時期、設計着手、着工、稼働の目標年月。
 2. 市・県に期待する支援（GX戦略地域の投資補助、系統整備、固定資産税の奨励金、許認可の伴走）。
 3. 自治体の新産業団地（分譲）を待てるか、民有地の先行取得を望むか。
 4. 契約上の前提（停止条件：受電容量の確保、開発許可、環境アセス等）。

（8）既存施設・民有地の転用
 1. 矢板市のゴルフ場（約120ha、丘陵、2027年12月閉鎖予定）を候補として検討する意向はありますか。
 2. 既存建物（クラブハウス等）の活用は不要か、更地渡しが条件か。
 3. 地権者が複数の土地（借地を含む）でも進められるか、一筆・一所有者が条件か。

（9）再エネ・蓄電池の併設
 1. DC用地に太陽光・蓄電池（BESS）を併設する構想はありますか。ある場合の規模（MW／MWh）と必要面積。ゴルフ場のうちDCに使わない丘陵部を太陽光・BESSに充てる案は検討対象になりますか。
 2. 脱炭素電源の調達方針（オンサイト再エネ、オフサイトPPA、非化石証書）。GX戦略地域の投資補助の活用を前提にするか。
 3. 系統用蓄電池で先行して系統接続を押さえ、DCの受電に転用する考え方を取るか。
