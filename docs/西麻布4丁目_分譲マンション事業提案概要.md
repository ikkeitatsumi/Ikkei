# 西麻布4丁目 分譲マンション事業 提案概要

作成日: 2026-09-08　　対象地: 東京都港区西麻布4-3-7（330.99㎡・100.12坪）　　前提の詳細は `西麻布4丁目_開発事業性検討レポート.md`

---

## 1. 提案の骨子

| 項目 | 内容 |
|---|---|
| 事業 | 低層・全7邸のワンフロア1邸型 高級分譲マンション |
| 土地取得価格 | **20億円（坪2,000万円）を指値**。上限21億円 |
| 建物 | RC造 地上7階・地下1階、延床約1,247㎡、専有約848㎡（257坪） |
| 販売 | 平均坪単価 **1,600万円**（1邸約125㎡・約6億円）、総売上 **41億円** |
| 収支 | 総事業費 33.6億円、**事業利益 7.4億円（売上比18%）** |
| 下振れ | 坪1,500万円でも利益5.0億円（13%）。損益分岐は坪1,311万円 |
| 期間 | 2026/12 契約 → 2027/7 着工 → 2028/12 竣工 → 2029/1〜3 引渡（約27か月） |

募集価格25億円のままでは坪1,800万円で売り切って初めて利益率15%に届く。**20億円なら坪1,600万円で18%、1,500万円でも13%**を確保でき、販売価格の下振れに耐える。提案の前提は土地価格の引き下げにある。

## 2. 商品企画

### 立地の読み
- 広尾駅徒歩7分、外苑西通りから1区画入った牛坂南側。西麻布の飲食・ナイトの喧騒から一歩引いた住宅街寄りの位置で、住宅商品として成立する。
- 周辺は5〜8階建の分譲・賃貸レジデンス（ブルーミング西麻布、アトラス西麻布、LA-RES西麻布等）。
- 100坪の敷地は大手ブランドの大規模物件が入らない規模で、**「小規模・全戸ワンフロア・プライベート性」**が差別化軸になる。

### 商品コンセプト：全7邸・ワンフロア1邸
| 階 | 住戸 | 専有面積（目安） | 想定価格（坪1,600万円） |
|---|---|---|---|
| 7F | ペントハウス 1邸（ルーフテラス付） | 約130㎡（39坪） | 約6.5〜7億円（プレミアム加算） |
| 3〜6F | 各1邸 × 4 | 約125㎡（38坪） | 約6.0億円 |
| 2F | 1邸 | 約120㎡（36坪） | 約5.6億円 |
| 1F | 1邸（専用庭・テラス） | 約100㎡（30坪） | 約4.6億円 |
| B1 | 機械室・トランクルーム・駐輪場（住宅は置かない） | ― | ― |
| 合計 | **7邸** | **約848㎡（257坪）** | **約41億円** |

- 各階1邸のため、エレベーターが各邸の玄関ホールに直結するプランが可能（プライベートロビー）。
- 2〜3LDK＋ウォークインクローゼット、天井高2.6m以上、全館空調、ホテルライクな共用部。
- 駐車場は附置義務の閾値未満のため任意。1F または B1 に2〜3台の機械式・平置きを検討し、なければ近隣月極を案内。

### ターゲット
- 国内富裕層のセカンドハウス・住み替え（麻布・広尾エリア内の移動需要）。
- 法人の役員住宅・迎賓用途。
- 外国人投資家（西麻布・広尾は海外の認知度が高い）。1邸5〜7億円は港区の億ション市場で標準的な価格帯。

## 5. 取得条件の提案

1. **価格 20億円**（坪2,000万円）。残余法の根拠を提示：坪1,500万円販売・利益率15%で払える上限が19.3億円。
2. **決済は賃借人退去後（2027年2月以降）**とし、退去遅延リスクを売主側に置く。現況決済とする場合は「2027年1月末までの明渡し」を売主の表明保証とし、遅延時の違約条項を入れる。
3. **保証金2,070万円**（B1B2）の返還債務承継分を代金から控除。
4. 契約前に**用途地域境界・高さ制限のボリュームチェック**（設計事務所、2〜3週間）を実施し、容積284%以下・6階以下が確定した場合は価格を再協議できる条項（または停止条件）を置く。
5. 確定測量・境界確認は売主負担。実測減の場合は面積精算。
6. アスベスト調査・地中障害物は売主負担または発見時精算。

## 7. 主要リスクと対応

| リスク | 影響 | 対応 |
|---|---|---|
| 容積率が284%（近商割合ゼロ）に留まる | 専有▲15坪、利益▲1.6億円 | 契約前のボリュームチェックで確定。価格再協議条項 |
| 高さ制限で6階止まり | 専有▲60〜70㎡ | 地下住戸で補う設計案を並行検討 |
| 建築費上昇（坪200万→230万） | 総事業費＋1.1億円 | 早期にゼネコン2社から概算取得、設計段階でVE |
| 販売価格が坪1,400万円に下振れ | 利益2.6億円（7%） | 全7邸のため販売期間を長く取れる。1邸ずつの価格調整が可能 |
| 退去遅延・立退料 | 事業開始遅れ、賃料継続は収入増 | 退去後決済、表明保証・違約条項 |
| 金利上昇（2%→3%） | ＋0.7億円 | 固定金利、早期完売による借入圧縮 |

## 8. 結論

- 分譲マンションは本件で唯一採算が取れる用途であり、**全7邸ワンフロア型・平均坪1,600万円**の企画で総売上41億円が見込める。
- 成立条件は**土地20億円前後での取得**。25億円では販売坪1,800万円が必須となり、2028〜29年の市況リスクを負う。
- 次の一手は、①ボリュームチェック（容積・高さの確定）、②20億円での指値提示、③ゼネコン概算の取得。この3点が揃えば事業判断ができる。
