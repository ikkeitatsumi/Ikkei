## 2. 特に注意すべき点（優先順）

1. **残置物特約で貸主に修繕義務が一切ない。** エアコン・トイレ・洗面台・キッチン・換気扇・照明・電気設備・内装・複合機まで残置物。築36年（1990年4月築）のため故障リスクが高く、本文第10条（貸主修繕）より特約が優先される。入居時の動作確認記録と、初期不良期間の貸主負担を交渉すべき。
2. **保証が二重。** 保証会社加入が契約条件でありながら個人連帯保証人も必要。どちらか一方にできないか確認。初回保証料が契約書に記載されていないので金額確認が必要。
3. **保証会社の継続保証料が代位弁済回数で跳ね上がる。** 0〜1回 10,000円／2回 159,200円／3回以上 318,400円。振込遅延1回が「代位弁済」に数えられると翌年の負担が大きい。
4. **造作買取請求権・有益費償還請求権の放棄（第16条3項）と退去時の全撤去（同2項）。** 2階で行う内装工事費は退去時に回収不能。
5. **内装工事には貸主の書面承諾が必要（第8条2項）で承諾料が発生し得る（同4項）。** 特約に「内装工事の実施」とあるが承諾の記載はない。工事内容の承諾と承諾料不要を書面で取得すること。
6. **エレベーター点検時に事前告知なしの立入りがあり得る特約。** 本文第17条より緩い。
7. **本店登記の移転は解約時に借主費用。** 現在の登記が「EARTH昭和町ビル1階」まで含む場合、今回の2階移転でも本店移転登記が必要になり得る（同一管轄内で登録免許税3万円）。
8. **消防・防災設備工事は借主が消防署協議のうえ実施。** 内装工事と合わせて見積が必要。
9. **排水管洗浄は借主負担。** 詰まりによる他テナント損害も借主負担。

## 3. 1階からの移転条項（特約末尾）

移転特約自体は借主に有利。2階引渡し（2026/10/1）から1階明渡し月までは2階賃料が発生せず、翌月から2階賃料に切替。ただし以下が未記載なので書面で確認する。

- 1階明渡しの期限と、期限超過時の扱い
- 「1階の賃料を適用」に水道代・ゴミ回収費が含まれるか
- **1階契約（定期借家、2027/9/30まで短期解約違約金543,600円）の解約予告・違約金・原状回復が今回の移転で免除されるか。** 特約は「移転に伴ったもの」と述べるのみで免除を明記していない。
- 1階契約の火災保険・保証会社契約の扱い（解約か2階へ引継ぎか）。1階の内装協力金390,500円の返還有無。

## 4. 記入漏れ・その他

- 契約締結日、借主TEL欄が空欄。
- 宅建業者欄が空白（1階契約では株式会社アクセスホームが宅建業者として記載）。仲介なしの直接契約であれば重要事項説明は行われない。
- 頭書(9)で第3条3項の日割りを解約月のみ不適用。開始は10/1のため開始時の影響なし。

## 5. 1階共同利用者（3社）への対応

1階は「事務所共同利用に関する同意書」により4枠（Golder＋乙丙丁）で共同利用中。移転に伴い次の書類を `output/` に作成した。

| ファイル | 内容 |

| 02_退去通知書_各社宛.docx | Golderから各社への個別通知（記書き形式） |
| 03_退去精算書兼チェックリスト.docx | 各社ごとの精算内訳・返還口座・チェックリスト・鍵返還記録 |
| 04_利益相反取引承認_株主総会議事録_Golder_Monde.docx | Golder・Mondeは代表者が同一（辰己）のため会社法356条の承認決議が必要。両社分のひな形 |

書類の生成スクリプトは `model/build_docs.js`（`npm install docx && node build_docs.js`）。

### 確認書・覚書に関する留意点

- 2階契約の「1年未満」の解約に違約金がかかるため、違約金なしで退去するには解約日を2027/10/1以降にする必要がある。3か月前予告のため、退去判断と貸主への申入れは2027/7/31までに行う設計にした。
- 名義株の確認書は税務上の論点（株式の帰属の認定、名義書換時の贈与・譲渡課税、相続税評価）があるため、税理士に確認のうえ使用すること。出資払込の事実を証する資料（振込明細等）を別紙に添付しておくと、名義株であることの立証に役立つ。
- 連帯保証人の交代には貸主の同意が不可欠。フォーシーズの保証のみへの切替、または新保証人の承諾のいずれかを貸主に事前打診しておくとよい。
