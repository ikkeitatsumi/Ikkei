# 不動産 事業性検討プロジェクト

同一の前提・書式で、物件ごとに用途別の収支を比較し、残余法で支払可能な土地価格を算出する。

## 案件一覧

### 1. 西麻布4丁目 土地（FACE西麻布）開発事業性検討

港区西麻布4-3-7 の土地（330.99㎡・募集価格25億円）について、ホテル / 分譲マンション / 賃貸レジデンス / 店舗ビル建替 / 現況保有 の収支を比較。

| パス | 内容 |
|---|---|
| `docs/西麻布4丁目_開発事業性検討レポート.md` | 結論・法規制・用途別収支・感度分析・残余法・交渉方針・DD項目・出典 |
| `docs/西麻布4丁目_分譲マンション事業提案概要.md` | 分譲マンション案の提案概要 |
| `output/西麻布4丁目_収支試算.xlsx` | 数式入り試算表。「前提条件」「分譲マンション」「ホテル」シートの青字セルを変更すると再計算 |
| `model/feasibility.py` | 収支モデル本体。`python3 model/feasibility.py` で全シナリオを標準出力 |
| `model/build_xlsx.py` | モデルから xlsx を生成。`python3 model/build_xlsx.py` |
| `source/FACE西麻布_物件概要書.pdf` | 仲介業者提供の概要書・地図・レントロール |

### 2. 姫路市夢前町戸倉 日生学園跡地（33.6ha）データセンター用地 適地・事業性検討

閉校した全寮制高校（自由ヶ丘高等学校）跡地 335,897㎡・募集価格16.5億円を、弊社の「土山町山中 データセンター適地調査」の評価フレーム（規模感 → 電力 → 通信・水・災害 → 許認可 → リスク → DDロードマップ）で検討。DC事業者の目線の収支と残余法、DC以外の出口（現況賃貸・蓄電池・太陽光・産業用地）の価格、受電回答を待つ間の保有コストを並べる。

| パス | 内容 |
|---|---|
| `docs/姫路夢前町_日生学園跡地_DC用地適地検討レポート.md` | 結論・物件整理・土山との比較・DC適性評価・収支・感度分析・残余法・代替出口・保有コスト・戦略・リスク・DDロードマップ・出典 |
| `docs/姫路夢前町_日生学園跡地_DC用地適地検討レポート.html` | 同レポートのHTML版 |
| `output/姫路夢前町_日生学園跡地_収支試算.xlsx` | 数式入り試算表。「前提条件」「DC事業」シートの青字セルを変更すると再計算 |
| `model/himeji_dc.py` | 収支モデル本体。`python3 model/himeji_dc.py` で規模別収支・感度・残余法・保有コスト・代替出口を標準出力 |
| `model/build_himeji_xlsx.py` | モデルから xlsx を生成。`python3 model/build_himeji_xlsx.py` |
| `source/姫路市夢前町戸倉_日生学園跡地_物件概要書.pdf` | 仲介業者（五軒邸）提供の概要書・配置図・基礎調査用資料（H6）・地図 |

## 使い方

```bash
pip install openpyxl
python3 model/feasibility.py         # 西麻布: シナリオ比較・感度分析・残余法
python3 model/build_xlsx.py          # 西麻布: output/ に xlsx を再生成
python3 model/himeji_dc.py           # 姫路: DC規模別収支・感度・残余法・保有コスト・代替出口
python3 model/build_himeji_xlsx.py   # 姫路: output/ に xlsx を再生成
```

前提を変えたい場合は各モデルの `Site` / `CommonCost` / `*Assume` データクラスの既定値を編集する。
